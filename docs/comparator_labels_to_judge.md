# Comparator Accuracy: Meaning Labels

For each original question below, mark **every** candidate that asks for the
same thing. There is no single right answer -- several candidates can be correct,
or none.

Write `y` or `n` after each candidate.

Candidates are shuffled, and the scores and rankings are hidden, so the labelling
is blind. Duplicate wordings have been merged.

## Why this exists

Every number we report today mixes four things: the generator, the comparator,
WebQSP's noisy path labels, and the searcher. When a number moves we cannot say
which one moved. These labels isolate the comparator: given candidates we *know*
the meaning of, does it rank a correct one first? That single number is what the
next round of work has to improve.
